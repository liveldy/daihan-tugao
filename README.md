# 代汉涂高

自中平元年黄巾起义（184）至咸熙二年晋王受禅（265），八十一载的回合制战棋策略游戏。
择一君主，招兵买马，依史而行，混一宇内。

> 「代汉者当涂高」出自《后汉书·公孙述传》所载光武帝与公孙述书，是理解袁术僭号与曹魏代汉的一条线索，也是本作标题所本。

在线试玩：<https://liveldy.github.io/daihan-tugao/>　·　[兵书志略](https://liveldy.github.io/daihan-tugao/wiki.html)　·　[匠作志略](https://liveldy.github.io/daihan-tugao/dev.html)

## 运行

纯静态、零外部依赖，直接双击 `index.html` 即可（全部脚本用传统 `<script>` 标签，`file://` 下可运行）。

若浏览器对本地文件有限制，起一个静态服务器：

```
python -m http.server 8931 --bind 127.0.0.1
# 然后访问 http://127.0.0.1:8931/index.html
```

## 玩法

- **择主**：六组十五家、二十六位君主。分组为「匡鼎炎汉 / 霸府挟令 / 乱世枭雄 / 边地雄踞 / 江东虎踞 / 苍天已死」，各有独立故事线与成败结局，且各带一条专属国策（如曹操「唯才是举」、刘协「天子诏书」、张角「太平道」）。
- **剧本与关卡**：一君多局、一局多关——二十六主共五十六局、二百七十二关（如 215 年「汉中之争」一局）。每关皆有定志：取某城、灭某势力、据城若干座以上、支撑至第若干回合，或尽有舆图城池；每局之末关则**开放型**，不设目标，唯待混一。志成之后「结束回合」即过关，过关屏示下一关、重挑战此关、关卡列表与还于主页面。择主界面下方有「疆场之记」一栏择局择关，军情顶栏常驻本关目标与进度，并有「关卡」一钮随时启关卡列表；逐关解锁，剧本亦逐局解锁（首局与该君主本传之局恒开）。已克之关记于浏览器本地，主页面示全局进展与「续战」。
- **回合**：一回合为一季，四时成岁。**点击舆图上本方部队即可调遣**（侧栏「军情」亦可），绿色格可移动，红框为可攻击的敌军与城池。右键或 Esc 取消选择。
- **舆图**：三十格宽、二十格高，凡六百格，皆作**正六边形**（尖顶、奇数行右移半格），每格有六邻。行军、射程、光环与反击皆按**六边距离**计，故斜向亦为一格。地形十四种之外，江海有津渡可涉，川泽有沼泽难行。
- **敌情**：点击任意敌军或城池，舆图左上浮出「敌情」牌：主将姓名、字号、五维、技能、兵种、兵力、士气、所处地形，以及与我方选中之军交锋的胜负预判。
- **行军与交战**：兵分十四种，各有相克（骑克弓弩、枪戟克骑、弓弩克枪戟、器械克城）。地形有攻守修正，山地阻器械，江海唯水军可渡。
- **攻城**：城池有守备，须先以野战军削弱守备，方得出兵入城。器械（云梯、冲车）攻城效率五倍于常兵。
- **经略**：城可增筑（提高守备与岁入），可征募各部曲，可为无将之军拜将。金帛用于征募、赏赐、邦交；粮秣为军食，不足则诸军减员。
- **庙堂**：与诸侯礼赂、约和、传檄。若为汉献帝，每六回合可下一道诏书——诏令天下共讨一贼、诏令罢兵、或征辟在野之士。
- **朝局（政治）**：庙堂之上另有党争、名分与储位三事。**党争**每十点减岁入百分之四，逾六十五则大臣见疑而去、郡县离心；**名分**正则民心自安、臣心自固；**储位**未定而国有诸子，则党争每合自增。朝会**议政**（屯田、盐铁、九品、察举、肉刑、租调、征役、兴学、大赦、宗室、宦者、水利、封赏、盟誓、迁都十五题），一回合止一事，耗金帛与威望而取一策；**立储**列诸子之资与名分，立嫡则朝纲稍安、废长立幼则众心未服。**政争事件**四十九事（魏讽之案、荀彧之死、董承之案、二宫之争、陆逊之死、高平陵之变、淮南三叛、高贵乡公之变、姜维避祸沓中、降魏之议……）依年依势而发，呈于朝堂，须抉择而后已，其后果动朝局、国力、邦交与人事。
- **典籍**：制度、历法、地理、人文、军事、思潮六类条目，随时查阅。
- **胜负**：一关之定志既成即过关；末关开放型者，拔尽天下城池则一统，写出该君主的成功结局。城池与部曲俱尽则败亡，写出其独有的失败结局。

## 分端（桌面／平板／手机）

同一份静态页，三种排布，皆在 `assets/style.css` 末「分端之式」一节：

- **桌面**（宽 > 900）：左右两栏——舆图占主区，侧栏 336px 常驻。
- **平板**（721—900）：一栏，舆图在上、侧栏在下，页签吸顶。
- **手机**（≤ 720）：顶栏排作四行（名号年月与「结束回合」／钱粮威望城池敌军／朝局与关卡庙堂／本关之志），高不及视口三分之一；舆图**不缩到看不清**，保 760px 之宽，指推左右观之（提示行亦明示「舆图可左右推移」）；主页面底栏吸底，「受命而起」常在目前；触控目标加大，去点击高亮与双击迟滞。
- **横持手机**（宽 ≤ 900 且高 ≤ 520）：复归左右并置，侧栏 300px。

不引前端框架：本作无构建、纯静态三页、vanilla 一万余行，换框架须重写并添构建链，风险与收益不成比例。

## 美术资源（自制图片）

图像**放进去即自动生效**，**缺图则自动回退为原有的文字与矢量绘制**，不会报错、不留白框、不会反复请求。后缀探测 `.png` → `.jpg` → `.webp`。

取图之法：只认**确证已得**之图，未就绪者立刻以文字旗绘出（故绝不先冒空框再消失），图既得就地换入；**每一名字只试一次**（试过即入缓存），同类同时至多探四名、全局十六名，余者排队依次探之——故缺图亦只是渐次试、非风暴，有图者必被寻得，绝不因省事而漏图。改图后刷新页面即可重探（控制台亦可一呼 `Art.reset()`）。

```
assets/img/portraits/<武将id>.png   人物头像（君主另可用 <君主key>.png）
assets/img/units/<兵种id>.png       部队标记（有主将头像时优先用头像）
assets/img/terrain/<地形key>.png    地形贴图（plain hill mount forest marsh desert water ford）
assets/img/banners/<势力key>.png    势力旗（可选）
assets/img/cities/<kind>.png        城池图形（duzhou zhouzhi zhongzhen xiancheng guanai gangkou）
```

全部应备文件名、建议尺寸与各 id 清单见 `assets/img/MANIFEST.md`，由 `node tools/art_manifest.js` 生成，可随时重跑。

## 版本

版本号四段——**主 . 次 . 修订 . 构建**：主号表格局之变，次号表功能之增，修订号表修缺与调平，构建号每提交必增。凡有改动必升版本，并记于 `CHANGELOG.md`。

同一版本号须同时见于三处，缺一即校验不通过：`VERSION`、`src/data/version.js` 的 `version`、`CHANGELOG.md` 最新一条标题。游戏主页面底栏与兵书／匠作二志顶栏皆显示此号。

当前为 **1.1.0.0「修整与适配」**（2026-10-22）：三事——其一，缺图不再留空框、不再重复请求（旧法先塞图再等三次 404，故每行每次重绘都先冒空框、故侧栏成片闪烁；实测旧法首次绘一面 352 次失败请求、其后十五次重绘又 193 次而 146 次重复，新法 264 次与 102 次而重复为零；今只认确证已得之图，未就绪者立刻以文字旗绘出，图既得就地换入，每一名字只试一次，探测有节）；其二，进度条瘦身，列表一律用数字，横条只留「朝局」一卡（地图首屏由九条降为无，庙堂叠层由二十四条降为二）；其三，分端之式——桌面、平板、手机三式与横持手机一式，手机顶栏排作四行不及视口三分之一，舆图窄屏保七百六十之宽可左右推移，触控目标加大，主页面底栏吸底。

当前版本见 [VERSION](VERSION)；历次改易见 [CHANGELOG.md](CHANGELOG.md)。

## 部署

### 预览版（GitHub Pages）

纯静态站，推到 GitHub 的 `main` 分支、以根目录开启 Pages 即可上线，无须构建。

```
penguin config vault set --key GITHUB_TOKEN --value <token>   # classic token，勾 repo 权限
sh tools/deploy_github.sh [仓库名] [--private]                # 默认 daihan-tugao、公开
```

脚本会建库（或沿用已有者）、推送 `main`、开启 Pages，并打印站点地址。token 只从环境变量读，不写入 `.git/config`。

### 正式版（自建服务端）

同一份静态站，由 `server/` 之服务端供应，另有账号、云存档、版本检查与管理员在线更新：

```
node server/server.js --port 8080 --web . --data ./server/data
```

首次启动会生成管理员令牌（`server/data/admin.token`）；于主页面「账号」处注册，**首位注册者掌管理之权**，
其界面即现「管理 · 在线更新」一栏：检查版本、发维护公告、施行更新（先生公告、拒新登录，待在线者自然下场
或逾时，方原子替换站目录）、必要时回滚。数据目录（用户、令牌、云存档）不入版本库。详见 `server/README.md`。

游戏主页面会标出本页所属：静态页为**预览版**，自建服务端所开为**正式版**。

## 史实原则

- 一切以《三国志》及裴松之注、《后汉书》《华阳国志》《晋书》《江表传》《吴录》《英雄记》《世语》《魏略》等正史为准。
- 不使用任何演义、戏曲、影视原创的人物与情节。貂蝉、周仓、关索、马云禄、秦琪等一概不取；「过五关斩六将」「温酒斩华雄」「三英战吕布」「草船借箭」「借东风」「空城计」「三气周瑜」一概不写。华雄依史写作「为孙坚所部枭首」，赤壁依史写作「周瑜主导、黄盖火攻」，三顾依史写作「凡三往，乃见」。
- 裴注所引传闻（如「七纵七擒」「死后见剖，胆如斗大」）在使用处均标明出自裴注，不作为正文。
- 结局中的年号、庙号、谥号与统一年份，凡史无明文者均属架空分支，与人物败亡处的史评原文区分标注。
