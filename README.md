# 代汉涂高

广义三国（184 黄巾起义 — 265 司马炎称帝）背景的回合制战棋策略游戏。
择一君主，招兵买马，依史而行，混一宇内。

> 「代汉者当涂高」出自《后汉书·公孙述传》所载光武帝与公孙述书，是理解袁术僭号与曹魏代汉的一条线索，也是本作标题所本。

## 运行

纯静态、零外部依赖，直接双击 `index.html` 即可（全部脚本用传统 `<script>` 标签，`file://` 下可运行）。

若浏览器对本地文件有限制，起一个静态服务器：

```
python -m http.server 8931 --bind 127.0.0.1
# 然后访问 http://127.0.0.1:8931/index.html
```

## 玩法

- **择主**：六组十五家、二十五位君主。分组为「匡鼎炎汉 / 霸府挟令 / 乱世枭雄 / 边地雄踞 / 江东虎踞 / 苍天已死」，各有独立故事线与成败结局，且各带一条专属国策（如曹操「唯才是举」、刘协「天子诏书」、张角「太平道」）。
- **回合**：一回合为一季，四时成岁。**点击舆图上本方部队即可调遣**（侧栏「军情」亦可），绿色格可移动，红框为可攻击的敌军与城池。右键或 Esc 取消选择。
- **敌情**：点击任意敌军或城池，舆图左上浮出「敌情」牌：主将姓名、字号、五维、技能、兵种、兵力、士气、所处地形，以及与我方选中之军交锋的胜负预判。
- **行军与交战**：兵分十四种，各有相克（骑克弓弩、枪戟克骑、弓弩克枪戟、器械克城）。地形有攻守修正，山地阻器械，江海唯水军可渡。
- **攻城**：城池有守备，须先以野战军削弱守备，方得出兵入城。器械（云梯、冲车）攻城效率五倍于常兵。
- **经略**：城可增筑（提高守备与岁入），可征募各部曲，可为无将之军拜将。金帛用于征募、赏赐、邦交；粮秣为军食，不足则诸军减员。
- **庙堂**：与诸侯礼赂、约和、传檄。若为汉献帝，每六回合可下一道诏书——诏令天下共讨一贼、诏令罢兵、或征辟在野之士。
- **典籍**：制度、历法、地理、人文、军事、思潮六类条目，随时查阅。
- **胜负**：拔尽天下城池则一统，写出该君主的成功结局；城池与部曲俱尽则败亡，写出其独有的失败结局。

### 键位

- `Enter` —— 结束回合
- `Esc` —— 关闭叠层／取消选择／收起敌情
- 鼠标右键 —— 取消选择

## 美术资源（自制图片）

图像**放进去即自动生效**，**缺图则自动回退为原有的文字与矢量绘制**，不会报错、不留白框。后缀探测 `.png` → `.jpg` → `.webp`。

```
assets/img/portraits/<武将id>.png   人物头像（君主另可用 <君主key>.png）
assets/img/units/<兵种id>.png       部队标记（有主将头像时优先用头像）
assets/img/terrain/<地形key>.png    地形贴图（plain hill mount forest marsh desert water ford）
assets/img/banners/<势力key>.png    势力旗（可选）
assets/img/cities/<kind>.png        城池图形（duzhou zhouzhi zhongzhen xiancheng guanai gangkou）
```

全部应备文件名、建议尺寸与各 id 清单见 `assets/img/MANIFEST.md`，由 `node tools/art_manifest.js` 生成，可随时重跑。

## 自检

```
node tools/validate.js          # 全量数据与引擎校验（含 wiki、故事线、全 25 主推演 12 回合）
node tools/sim.js caocao 40     # 以曹操自动推演 40 回合
SIM_AI_PLAYER=1 node tools/sim.js zhangjiao 260   # 以张角自中平元年推演 260 回合
node tools/art_manifest.js      # 重生成美术资源清单
```

## 史实原则

- 一切以《三国志》及裴松之注、《后汉书》《华阳国志》《晋书》《江表传》《吴录》《英雄记》《世语》《魏略》等正史为准。
- 不使用任何演义、戏曲、影视原创的人物与情节。貂蝉、周仓、关索、马云禄、秦琪等一概不取；「过五关斩六将」「温酒斩华雄」「三英战吕布」「草船借箭」「借东风」「空城计」「三气周瑜」一概不写。华雄依史写作「为孙坚所部枭首」，赤壁依史写作「周瑜主导、黄盖火攻」，三顾依史写作「凡三往，乃见」。
- 裴注所引传闻（如「七纵七擒」「死后见剖，胆如斗大」）在使用处均标明出自裴注，不作为正文。
- 结局中的年号、庙号、谥号与统一年份，凡史无明文者均属架空分支，与人物败亡处的史评原文区分标注。
